VibeBlox - how to build (Windows)

1. Install Node.js (LTS) from https://nodejs.org
2. Open Command Prompt (cmd) - not PowerShell - and go into this folder:
      cd C:\Users\YOURNAME\Downloads\vibeblox
3. Run:
      npm install
      npm run build
4. The finished game is in the "dist" folder. Upload the CONTENTS of dist
   (index.html, assets, images, music) - that is what CrazyGames wants.

To try it on your PC first:  npm run dev   (then open the address it prints)
